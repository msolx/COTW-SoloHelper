# COTW SoloHelper 单人助手

**v1.1.0 · Windows 10/11 x64 · 作者 msolx**

《猎人：荒野的召唤》单人辅助工具。

[下载 v1.1.0](https://github.com/msolx/COTW-SoloHelper/releases/tag/v1.1.0) · [English](../README.md)

## 功能

| 功能 | 实际效果与限制 |
| --- | --- |
| 航点快速移动 | 将用户航点临时变成帐篷式图标，由你在地图点击快速移动。选择干燥无障碍地面，不保证任意落点安全。 |
| 蹲行加速 | 默认1.5倍，可设1～10倍，重启游戏后应用。噪声可能增加；尚未实现游戏中热调或爬行倍率界面。 |
| 负重 | 默认基础负重512kg，不改变物品重量，保留背包加成。 |
| 观察高亮时间 | 默认120秒，可调至999秒，需已学习Tag技能；正常卸载和标记规则仍可能使高亮消失。 |
| FOXPRO X360 | 可选400米范围和100%基础吸引概率，动物AI的其他条件仍会影响响应。 |
| 清除已有压力区 | 清除当前保护区已产生的压力，不阻止后续新增压力、不恢复消失的需求区。 |

## 安装

1. 在Release的 **Assets** 中下载 **COTW_SoloHelper_v1.1.0.zip**，不要下载Source code源码包。
2. 完整解压到可写目录，保留 `_internal` 等配套文件，无需安装Python。
3. 运行 `COTW_SoloHelper.exe`。找不到游戏时，在“维护 → 选择游戏安装根目录”中选择包含 `theHunterCotW_F.exe` 的文件夹。

## 使用

**静态参数：** 正常退出游戏，确认单人，设置参数后点击“应用设置”，再“加载Mod启动游戏”。只改数字不会更新正在运行的游戏。Mod安装在 `navigator_solo`；卸载前退出游戏，再通过维护菜单卸载。其他启动参数或Mod仍可能冲突。

**航点传送：** 在单人游戏的干燥无障碍陆地设置航点，在Helper确认单人和本次落点、启用临时帐篷。等“已就绪”后，回地图只点击该临时图标快速移动**一次**。等待期间不要重设航点或点真实帐篷；加载、清理完成后核对落地和走动。提交前可取消等待，但取消不会撤销已提交的传送；清理尚未结束时不要强制关闭Helper。

**压力区：** 在压力页读取、清除已有压力，重开游戏地图核对。之后狩猎仍会产生压力。

快捷键仅在Helper窗口有焦点时有效：**Ctrl+Shift+T** 启用航点传送，**Ctrl+B** 生成文件，**Ctrl+L** 加载Mod启动。不是全局游戏快捷键。

## 重要说明

**仅供单人模式使用。SoloHelper会修改游戏内存**，用于明确确认后的航点及压力操作，也会生成本地参数Mod。不直接编辑存档文件，但正常游戏保存可能保留状态变化。勾选单人不等于程序能自动阻止进入多人房间。
