# COTW Solo Helper 单人助手

本仓库是独立Helper源码，**并非只读工具**。航点和压力功能会在用户明确确认后使用Windows用户态内存写入；静态Mod会从用户自己的游戏提取资源并安装到本工具独占目录。没有DLL注入、Hook、驱动、远程游戏函数调用或保护绕过。

支持Windows10/11 x64单人模式，既有现场记录对应build25131233及EXE SHA256：
`89dbab025114090c91a63ae7f0533ee84eee3c48f4b8543224b359c31b794c22`。
游戏更新后不能通过强制跳过校验保证兼容。

## 界面和用法

四页：航点传送、单人参数、压力区、操作记录。

- 静态参数：完全退出游戏→勾选单人→设置倍率/容量等→应用设置→从Helper加载Mod启动游戏。只在UI改数字不会修改正在运行的游戏。
- 航点传送：在游戏放置能确认干燥无障碍的用户航点→Helper确认单人和本次地面→启用临时帐篷→等就绪→回游戏只点击该临时图标快速移动一次。取消等待不等于已提交后传回原地。
- 压力区：读取并按需清当前保护区已有压力；以后仍会产生压力，不恢复已消失需求区。游戏正常保存可能保留清除后的状态。
- 快捷键仅Helper获得焦点时有效：Ctrl+Shift+T启用临时帐篷，Ctrl+B仅生成，Ctrl+L启动已安装Mod。

原生航点路线目前无固定水平距离上限、高差配置1000米，加入较宽网格容差和航点高度回退；这些不等于任意水域、山顶、障碍落点安全。检查实际落地/走动，落地未确认和异常不当作成功。

普通蹲行默认1.5倍、可设1～10倍；噪声可能增大，未完成保持原噪声或运行中热调，也没有可用爬行倍率UI。基础负重默认512kg，背包加成保留。高亮默认120秒、120～999可调，依赖已学Tag。电子哨可选400米和100%基础概率，仍受其它AI条件影响，不保证所有动物响应。
